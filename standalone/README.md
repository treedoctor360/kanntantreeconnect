# 単一HTMLファイル版（庁内環境向け）

`kantantree-standalone.html` は、**このファイル1つだけで動く**「かんたん樹木登録」です。
外部のライブラリを読み込めない庁内環境で使うために、本体（React版）を素のJavaScriptへ
書き直しました。インターネット接続・インストール・ビルドは要りません。

## 使い方

1. `kantantree-standalone.html` を端末（またはUSB・共有フォルダ）にコピーする
2. ダブルクリックでブラウザ（Edge / Chrome / Safari）で開く
3. 「設定」タブで公園を登録 → 「登録」タブで1本ずつ登録する

サーバに置いて `https://.../kantantree-standalone.html` として開く形でも同じように動きます。

> **最初にすること**: 設定タブ →「＋ 公園を追加」。公園が1つも無いと樹木を登録できません。
> 市の公園一覧CSVがあれば「📤 CSVから取り込む」でまとめて登録できます。

## 本体（React版）との違い

| | 本体 | 単一ファイル版 |
|---|---|---|
| 外部ライブラリ | React / Dexie / Leaflet | **なし**（このファイルだけ） |
| スプレッドシート連携（GAS同期） | あり | **なし** |
| GPS（現在地の取得） | あり | **なし** |
| 地図タブ | あり | **なし**（タブは 登録・一覧・設定 の3つ） |
| 書き出し | JSON / CSV / GeoJSON | **Excel（.xlsx）** / JSON / CSV（GeoJSONは座標を使わないので省略） |
| 保存先 | 端末内（IndexedDB） | 端末内（IndexedDB。使えない環境では localStorage） |

**同じもの**: 点検項目・選択肢・凡例の文言、テープ番号と樹木番号の採番、公園名の
表記ゆれ照合、紙の調査票（A4横2枚）、CSVの列（スプレッドシートと同じ英字の項目名・40列・
並びも同じ）、JSONバックアップの形式。

## データの持ち運び

保存先はブラウザの中（端末ごと）です。**別の端末へは自動では伝わりません。**

- 端末を移すとき・バックアップ … 設定タブ →「JSON 写真あり」
- 本体（React版）とやり取りするとき … どちらも設定タブの JSON 書き出し／読み込みが使えます。
  読み込みは「追記マージ」（同じ id は更新日時の新しい方を採用、知らない id は追加）なので、
  上書きで消える心配はありません
- **Excelで見る・台帳へ転記するとき** … 「Excel（.xlsx）」。項目名は日本語で、
  そのままExcelで開けます。シートは3枚（樹木 / 公園 / 凡例）。1行目は固定＋フィルタ付き。
  段階もの（葉の茂り・活力度）の 1〜4 の意味は「凡例」シートを見てください
- **スプレッドシートへ貼り付けるとき** … 「CSV（英字）」（UTF-8 BOM付き）。
  項目名も並びもスプレッドシートの `trees` シートと同じ（`id` / `parkCode` / `tapeNo` …）なので、
  見出し行を除いてそのまま貼り付けられます。1〜4 の意味は「CSV 凡例」に出ます
  （`field` 列が本体CSVの項目名と同じなので突き合わせられます）

> CSVに公園名の列はありません（スプレッドシートの `trees` シートに無いため）。
> 公園名が要るときは Excel を使ってください（`公園名` の列が入っています）。

緯度・経度はこの版では入力できませんが、**本体で入れた座標は読み込んでも消えません**
（そのまま持ち続け、JSON・CSVに書き出します）。

## 保存先について（画面右上の表示）

| 表示 | 意味 |
|---|---|
| 端末内に保存 | IndexedDB。ふつうはこれ。写真も入る |
| 簡易保存 | IndexedDB が使えず localStorage を使っている。容量が小さい（おおむね5MB）ので、写真を多く入れると保存できないことがある。こまめにJSONバックアップを取ること |
| 保存できません | どちらも使えない環境。入力内容は閉じると消える。作業のあとに必ずJSONで書き出すこと |

ブラウザの「閲覧履歴・サイトデータの削除」を行うと、**登録した内容も一緒に消えます**。
定期的にJSONバックアップを取ってください（7日以上取っていないと設定タブで赤く出ます）。

## 中身を直したいとき

1ファイルですが、中は本体のファイル構成と同じ順に区切ってあります（§1 点検項目の定義 …
§12 起動）。点検項目を足すときは §1 の定義に足し、§5 の列定義（`TREE_COLUMNS`。英字名・
日本語名・値の取り出し方を1か所にまとめてあり、CSVもExcelもここだけを見ます）と
§9 の保存処理（`handleSave`）をそろえてください。
Excel（`§5-2`）は外部ライブラリを使わず、xlsx（＝XMLをZIPで固めたもの）を自前で
組み立てています（無圧縮ZIP）。紙の調査票（§6）は §1 の定義から
組み立てるので、`SHEET_COLUMNS` に列を足すだけで凡例まで自動でつきます
（列幅の合計は281mmに戻すこと）。

## 開けない（画面が真っ白になる）とき

**文字コードが UTF-8 から変わっていないか**を確かめてください。メモ帳などで開いて
「ANSI」で保存し直すと、日本語が壊れて動かなくなります（コピーするだけなら問題ありません）。

文字コードが変わっている場合は、画面に「開けませんでした」という案内が出ます。
配布された元のファイルをもう一度コピーして開き直してください。
