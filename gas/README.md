# スプレッドシート連携（GAS）の設置手順

アプリ（GitHub Pages）から直接スプレッドシートを触ることはできない。
あいだに **GAS（Google Apps Script）の Web App** を1枚はさんで中継させる。

```
スマホのアプリ  ──POST（JSON）──▶  GAS Web App  ──▶  スプレッドシート
（GitHub Pages）  ◀──JSON────────
```

所要 10分ほど。パソコンで作業すること。

---

## 1. スプレッドシートを作る

1. Googleドライブで**空のスプレッドシート**を新規作成する
2. 名前を分かりやすく変える（例 `樹木登録データ`）

シート（タブ）は**作らなくてよい**。`parks` / `trees` / `deletions` の3枚は
初回の同期のときにスクリプトが自動で作る。

## 2. スクリプトを貼り付ける

1. そのスプレッドシートで **拡張機能 → Apps Script** を開く
2. 最初から入っている `function myFunction() {}` を**全部消す**
3. このリポジトリの [`gas/Code.gs`](./Code.gs) の中身を**全部貼り付ける**
4. 💾（保存）を押す

## 3. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車⚙ → **ウェブアプリ** を選ぶ
3. 次のように設定する

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | `樹木登録 同期 v1.0`（何でもよい） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

   > 「アクセスできるユーザー」を**全員**にしないと、アプリからは
   > JSONではなくGoogleのログイン画面（HTML）が返ってきて同期できない。
   > 「全員」でも、**URLを知っている人だけ**が触れる。URLは人に見せないこと。
   > 心配なら手順5の「合言葉」を設定する。

4. **デプロイ**を押す。初回は権限の確認が出るので許可する
   （「このアプリは確認されていません」→ 詳細 → 安全でないページに移動、で進む）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピーする

## 4. アプリ側に貼り付ける

1. スマホ（またはパソコン）でアプリを開く
2. **設定タブ → スプレッドシート連携（GAS）**
3. URL欄にコピーしたURLを貼り付け、**接続テスト** を押す
   - 「つながりました。シート「樹木登録データ」…」と出れば成功
4. **保存** を押す

これで完了。以降は次のように動く。

- **アプリを開くたび**にシートの内容を取り込む（他の端末で登録したものが入ってくる）
- **登録・編集・削除のたび**に自動でシートへ送る（数秒待ってからまとめて送る）
- 圏外のときは端末内に溜め、電波が戻ったときに送り直す
  （ヘッダー右上のバッジに「◯件待ち」と出る）

## うまくいかないとき（まずこれ）

**Web AppのURL（末尾 `/exec`）を、そのままブラウザのアドレスバーに貼って開く。**
`Code.gs` が自己診断のJSONを返すので、どこで止まっているかがすぐ分かる。

| 開いたときの表示 | 意味 | 直し方 |
|---|---|---|
| `{"ok":true, ...}` と出る | 中継は動いている | このURLをアプリの設定タブに貼る。それでも同期できなければ下の「それでも駄目なとき」へ |
| **Googleのログイン画面**が出る | デプロイの「アクセスできるユーザー」が「全員」になっていない | デプロイを管理 → 編集（鉛筆）→ アクセスできるユーザーを**全員** → **新しいバージョン**でデプロイ |
| `"checks":{"spreadsheet":{"ok":false ...}}` | スクリプトがシートに紐づいていない（スタンドアロンで作った） | シートを開いて **拡張機能 → Apps Script** から作り直す。または プロジェクトの設定 → スクリプト プロパティ で `SPREADSHEET_ID` にシートのURLを登録 |
| **404 / スクリプトが見つかりません** | まだデプロイしていない、またはURLが違う | 手順3をやり直す。URLの末尾は `/exec`（`/dev` は本人しか開けないテスト用なので使わない） |
| **エラー画面**（赤い文字） | コードの貼り付けが途中で切れている | `gas/Code.gs` を**全部**貼り直して保存し、新しいバージョンで再デプロイ |

**シートに `parks` / `trees` / `deletions` の3枚ができていない場合は、一度も正常に動いていない。**
この3枚は最初のリクエストで自動的に作られるので、シートが「シート1」だけなら
上の表のどれかに当てはまっている。

### それでも駄目なとき

- **コードを直したら必ず再デプロイする。** 保存しただけでは公開中のWeb Appは古いまま。
  「デプロイを管理 → 編集 → バージョン: **新しいバージョン** → デプロイ」。
  こうするとURLが変わらないので、アプリ側の設定を直さずに済む。
- **初回だけ時間がかかる。** シート3枚を作るため、最初の1回は十数秒かかることがある
  （アプリ側は45秒まで待つ）。2回目からは速い。
- Apps Script の画面で **実行数（左メニューの「実行数」）** を見ると、リクエストが
  届いているか・どこで失敗したかが分かる。

## 5.（任意）合言葉を設定する

URLだけで誰でも書き込める状態が気になる場合。

1. Apps Script の画面で **プロジェクトの設定（歯車）→ スクリプト プロパティ**
2. `SYNC_TOKEN` という名前で、好きな文字列（推測されにくいもの）を登録する
3. アプリの設定タブの「合言葉」欄に**同じ文字列**を入れて保存する

合言葉が合わないリクエストは弾かれる。

> 合言葉やWeb AppのURLは、チャット・コミット・スクリーンショットに載せないこと。

## スプレッドシートの中身

### `parks` シート（公園）

| 列 | 意味 |
|---|---|
| id | UUID（他のアプリと突き合わせるときの主キー） |
| code | 公園コード（`P001`） |
| name | 公園名 |
| lat / lng | 代表座標 |
| note | メモ |
| pid | 台帳側のID（CSV取込で入る。無ければ空） |
| lastUsedAt / createdAt / updatedAt | 日時（ISO 8601） |

### `trees` シート（樹木）

列の並びは紙の **「樹木点検 現地チェックシート」1ページ目**に合わせてある。

| 列 | 紙の欄 | 入る値 |
|---|---|---|
| id | — | UUID |
| parkId / parkCode | 場所 | 所属する公園（公園名は `parks` シートを引く） |
| tapeNo | テープ番号 | `12` など |
| treeNo | 樹木番号 | 公園コード＋テープ番号（`P001-012`） |
| species | 樹種（不明可） | 樹種和名。`不明` も可 |
| height | 樹高 | m（数値）。目分量 |
| leafDensity | 葉の茂り | `濃` `普` `ま` `ほ` |
| fungus | キノコ | `有` `無` `未` |
| fungusPart | キノコ部位 | `根` `幹` `枝` `枯` `不`（複数は `根・幹` のように `・` でつなぐ） |
| cavity | 空洞・傷 | `有` `無` |
| cavityPart | 空洞・傷の位置 | `根` `幹` `枝`（複数可・`・` でつなぐ） |
| trunkDamage | 幹の損傷 | `有` `無` |
| barkInclusion | 結合部の異常(入り皮) | `有` `無` |
| frass | フラス | `有` `無` `未` |
| envRoad / envWire / envBuilding | 周辺環境 道路園路 / 電線 / 建物 の有無 | `有` `無` |
| envNote | 周辺環境 備考欄 | 自由記入 |
| caution | 注意 | 自由記入 |
| photoCount | 写真 | 登録した端末での**枚数**（写真そのものは送らない） |
| surveyDate / surveyor / tapeRoll | 調査日 / 調査者 / テープロール | 表頭の項目。`2026-08-20` / 氏名 / `A` `B` `C` |
| lat / lng / accuracy / coordSource | — | 座標・誤差(m)・入力元（gps/map/manual/link） |
| girth | — | 幹周(cm) |
| note | — | メモ（注意とは別。アプリ側の任意項目） |
| registeredAt / updatedAt | — | 日時（ISO 8601） |

> **列を変えたときは3か所そろえる**: `gas/Code.gs` の `SHEETS`、アプリ側
> （`src/lib/io.js` の `CSV_COLUMNS` と登録処理）、この表。
> すでにシートを作ったあとで列を足した場合は、次の同期のときに `Code.gs` が
> 見出し行を作り直し、既存の行を新しい列の位置へ並べ替える（値はずれない）。
> 消した列の値は捨てられるので、列を減らすときは先にシートの控えを取ること。

### `deletions` シート（削除の記録）

消したことを他の端末に伝えるための記録（tombstone＝墓標）。
`id` / `table` / `at` の3列だけ。**手で消さないこと**（消すと、他の端末で
消したはずのデータが復活することがある）。全端末の同期が済んだあとで
掃除したいときは、Apps Script の画面で `pruneDeletions` を実行する（90日より前の記録を消す）。

## 気をつけること

- **写真はシートに送られない。** Base64の画像は1セルの上限（5万文字）に載らないため。
  紙の「写真」欄にあたるものとして、`photoCount`（枚数）だけを送っている。
  写真そのものは登録した端末の中にある。
  写真は端末内に残るので、機種変更のときは従来どおり
  設定タブの「JSON 写真あり」でバックアップを取ること。
- **樹種マスタ・使用回数もシートに送らない**（端末ごとの使い勝手の設定のため）。
- **セルを手で直してもよい。** 直した行は次の同期でアプリに反映される……
  **わけではない**。アプリは `updatedAt` の新しい方を採用するので、手で直したときは
  同じ行の `updatedAt` も現在時刻のISO形式（例 `2026-08-19T12:34:56.000Z`）に
  書き換えること。書き換えないと、次にその樹木をアプリで編集したときに上書きされる。
- **同じデータを2台で同時に編集した場合**は、`updatedAt` の新しい方が残る（後勝ち）。
