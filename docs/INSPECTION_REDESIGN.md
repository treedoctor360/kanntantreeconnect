## 1. コード化の原則

- **段階もの（順序に意味がある）** → 値は `'1'`〜`'4'` の文字列。**1＝良い/充実 側**に統一（国交省の活力度に合わせる）。
- **状態もの（有/無/未）** → 語のまま。略語ではなく完全な語で、改称リスクが無く、「未」を潰さないため。
- **表示ラベルと保存値を分離** する。`inspection.js` の各選択肢を `{ value, label, hint }` の形にし、
  画面は `label`、保存・CSV・シートは `value` を使う。ラベルを変えても保存値は不変。
- **CSVには凡例を添える**（下記5）。

## 4. 「幹の損傷」の整理（HANDOVERの宿題を解く）

### 4-1. 変更内容

曖昧だった `trunkDamage`（幹の損傷・有/無・定義なし）を、国交省の主要項目に分解する。

| 新フィールド | 画面ラベル | 値 | 由来 |
|---|---|---|---|
| `trunkCrack` | 樹幹の亀裂 | 有/無 | 国交省 主要項目⑦ |
| `trunkLean` | 樹幹の不自然な傾斜 | 有/無 | 国交省 主要項目⑥ |

（`trunkDamage` は廃止。国交省の「樹幹の揺らぎ」⑤は倒木直前サインで、必要なら `trunkSway` として後日追加できる。今回は見送り可。）

### 4-2. cavity（空洞・傷）との重複 ← ここだけKohの判断が要る

現行 `cavity` の定義は「穴・樹皮の広範囲な剥離・**割れ目**があった」。
このうち「割れ目」は国交省の**「樹幹の亀裂」`trunkCrack` と重複**する。切り分け案は2つ。

- **案A（推奨）**: `cavity` は「空洞（穴）・樹皮剥離」に限定し、割れ目/裂けは `trunkCrack` に寄せる。
  → 概念が国交省ときれいに一致する。cavity の hint を「穴・樹皮の剥離」に直す。
- **案B**: `cavity` は現行のまま（割れ目も含む）、`trunkCrack` は「幹を貫く/大きい亀裂」に限定して併存。
  → 現場の判断が「これは cavity か crack か」で迷いやすい。

**樹木医としてどちらが現場実態に合うか**、Kohに選んでほしい。既定は案A。

### 4-3. 既存データの移行（正直に扱う）

旧 `trunkDamage='有'` は、亀裂か傾斜かの区別情報を持たない。**推測で振り分けない。**

- 旧値を `trunkDamageLegacy` 列に退避して保存（消さない）。
- 新 `trunkCrack` / `trunkLean` は旧レコードでは空欄のまま。
- 「`trunkDamageLegacy` に値がある＝要再確認」の樹木一覧を移行時に出力する。
  データ数が少ないので、次回巡回で拾い直せる。

## 5. WebGIS用「重点観察区分」の派生列

生の項目は消さず、**エクスポート時に1列だけ算出**する。WebGISはこの列だけで色を塗る。

| 区分 `alertLevel` | 色 | 条件 |
|---|---|---|
| `3` 重点 | 赤 | `fungus='有'` または `frass='有'` |
| `2` 注意 | 黄 | `cavity='有'` / `trunkCrack='有'` / `trunkLean='有'` / `barkInclusion='有'` のいずれか |
| `1` 通常 | 緑 | 上記なし・点検済み |
| `0` 未 | 灰 | 点検項目が未入力、または `fungus='未'` のみで他に所見なし |

- 名称は**「重点観察区分」**。危険度・診断結果ではなく**観察の優先度**である旨をCSVヘッダ注記に明記する。
- 実装は `src/lib/inspection.js` に `alertLevel(tree)` を追加（`inspectionBadges` の隣）。純粋関数。
- CSV / GeoJSON / シートに `重点観察` 列として出す。GeoJSON では WebGIS の色分けプロパティになる。

## 6. CSVの可読性（凡例）

段階が 1〜4 になるので、値だけでは読めない。対応として:

- CSVの**先頭に凡例行**は入れない（機械取込を壊すため）。代わりに:
  - **別途「凡例」シート/凡例CSV**を書き出す（`葉の茂り: 1=密,2=普通,3=まばら,4=ほとんどない` 等）。
  - GASシートには **`凡例` シートを1枚**用意して常設する。
- 【要確認】一覧で読みやすさを優先するなら、段階項目だけ「値＋ラベル」の2列出力にもできる
  （例: `葉の茂り` 列＝`2`、`葉の茂り_表示` 列＝`普通`）。列が増えるが読みやすい。**既定は値のみ＋凡例シート**。
